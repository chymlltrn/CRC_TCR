# Data availability · 数据可用性

[English](#english) | [简体中文](#简体中文)

## English

**Current status (21 October 2026): code is public; Source data have not yet been released.**

The figure source data and supporting numerical results are retained in the authors' server archive. They are not stored in this repository, any branch or tag, or a GitHub release attachment. Data are not published as part of the code visibility change.

Source data are planned for a separate later release. The release date and public location have not yet been set. This page will be updated with the data link, version, and scope when that release is ready. No automatic release date has been configured.

Raw participant-level records, real TCR sequences, and third-party restricted files retain their applicable consent and access conditions; their release is not implied by the planned figure Source data release. Public reference datasets and pretrained software/model resources remain subject to their original providers' terms and are obtained separately as documented in each module.

GitHub visibility applies to a whole repository. A folder or branch inside this public repository cannot serve as a private data store. Actual inputs, private configurations, outputs, and data archives must remain outside this checkout until separately reviewed for release.
