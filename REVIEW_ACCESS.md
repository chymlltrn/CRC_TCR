## English

Repository: https://github.com/chymlltrn/CRC_TCR

The code repository is public from 21 October 2026. Editors, reviewers, and other readers can browse or clone it without an invitation or GitHub login. Source data remain unreleased and are managed separately; see [data availability](DATA_AVAILABILITY.md).

| Version | Meaning |
| --- | --- |
| `v29-public-20261021` | Public code release with Chinese and English documentation and residual sample-identifier anonymization; calculation logic is preserved. |
| Original review snapshot | Retained separately in a private archive for provenance. Its Git history is not part of this public repository. |

Use the tag cited in the manuscript to identify the intended snapshot. The public repository starts from a reviewed, clean snapshot. No participant data, actual TCR sequences, pretrained weights, or result tables are included in its Git history. Configuration examples contain placeholders; actual configurations remain outside the checkout. Data access conditions and software licenses are separate from repository visibility.
